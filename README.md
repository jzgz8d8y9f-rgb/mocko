# Mocko — Interview Practice

A single-page prototype for practicing job interviews. Two modes:

- **HireVue Practice** — record an answer on camera, get a scored breakdown (structure, clarity, pace, eye contact, tone) with specific pointers.
- **Mock Interview** — a live voice conversation with an AI interviewer that asks follow-ups.

Also includes standalone **Drills** (STAR Builder, Spot the Filler, Mental Math Sprint) and a **History & Trends** view for tracking progress across sessions.

## Status

Prototype only — recording, grading, and voice are all simulated with mock data. No backend.

## Running it

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
